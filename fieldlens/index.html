FieldLens for Jira — Custom Field & Context Auditor

Audit Jira Cloud custom field bloat, detect duplicate field clusters (including type mismatches), flag global-context performance drag, and export safe IT change-control cleanup plans — without ever moving data outside Atlassian's cloud.

Documentation & Quick Start

  1. Install FieldLens for Jira from the Atlassian Marketplace onto your Jira Cloud site.
  2. Navigate to Jira Settings → Apps → FieldLens — Custom Field Auditor.
  3. Review your Instance Health Score (0–100, Grade A–F), orphaned fields (0 screens + stale), duplicate clusters, and global-context bloat flags.
  4. Click Check Count on any candidate field to verify live issue usage via JQL (cf[ID] is not EMPTY) before deleting it manually in Jira Settings.
  5. Open the Cleanup Plan Export (MD / CSV) tab to copy a formula-safe CSV or Markdown IT change-control checklist.

Privacy Policy & Data Security

Effective Date: November 21, 2026 · Vendor: Benchwork Tools

  • Runs 100% on Atlassian Forge (Zero Data Egress): All backend functions and UI components execute natively inside Atlassian's managed Forge cloud runtime. Zero customer data is transmitted to external servers, third-party analytics, or external sub-processors.
  • Least-Privilege Read-Only Scopes: FieldLens requests only read:jira-work (read-only access to custom field metadata and on-demand JQL counts) and storage:app (Atlassian-hosted Forge KVS). FieldLens cannot delete, rename, or modify Jira issues or configuration.
  • Zero Personal Data Stored: FieldLens never stores issue titles, descriptions, comments, attachments, emails, or user account IDs. Only aggregate numeric trend snapshots (timestamp, health score, total custom fields, orphaned/duplicate/bloat counts) are stored inside Atlassian's Forge app storage.
  • Data Deletion: Uninstalling FieldLens from your Jira Cloud site automatically removes all app storage in accordance with Atlassian's Forge lifecycle policy.
